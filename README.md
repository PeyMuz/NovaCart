# NovaCart 🛒

NovaCart is a responsive front-end e-commerce website built using HTML, CSS, and JavaScript.

Designed with a clean and modern shopping experience in mind, NovaCart lets users browse products, view details, add items to cart, and switch between light and dark themes.

## ✨ Features

- Responsive design (desktop, tablet, mobile)
- Modern landing page
- Product listing page
- Product details page
- Shopping cart page
- Contact page
- About page
- Account page
- Light theme (White + Blue)
- Dark theme (Black + Gold)
- Smooth UI interactions
- Local storage support
- Interactive navigation menu

## 🛍️ Product Categories

NovaCart includes products like:

- Fashion items
- Tech accessories
- Gaming gear
- Computer hardware
- Collectibles / toys (like Omnitrix-inspired items)

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (Vanilla JS)
